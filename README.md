# ❓ FAQ

### What is Frame Generation 2026?

A PC gaming performance toolkit for organizing frame-generation configurations, FPS results, frame-pacing observations, and benchmarks.

### Does every game support frame generation?

No. Availability depends on the game, hardware, drivers, and supported technology.

### Does frame generation double performance?

Not necessarily. Displayed FPS can increase substantially, but results vary and generated frames do not have the same performance characteristics as increasing the underlying render rate.

### Should I track base FPS?

Yes. Base rendering performance remains useful when evaluating responsiveness and overall frame-generation results.

### Can I compare DLSS, FSR, and XeSS?

Yes, when the game and hardware provide the relevant options.
